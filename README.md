## 🌟 Features & Highlights

- **Dynamic Next.js 15 & React 19 App Router**: Ultra-fast performance with dynamic real-time catalog updates and Server-Side Rendering (SSR).
- **Prisma ORM & SQLite Database**: Relational schema powering multi-variant product matrixes, categories, orders, discount coupons, banners, and 3D showcases.
- **Bilingual Internationalization (AR / EN)**: Full RTL & LTR layout support (Cairo font for Arabic, Inter font for English).
- **Advanced Product Variant Matrix**: Independent multi-photo color option swatches, sizes (`S`-`XXL`, `30`-`45`), and per-color stock management.
- **Visual Order Fulfillment Dashboard**: Real-time order tracking with high-resolution product photos, color-resolved thumbnails, and single-click WhatsApp order processing.
- **Interactive 3D WebGL Showcases**: Three.js WebGL interactive 3D model previews for footwear and street drops.
- **Google Maps Integration**: Direct Google Maps store location integration (`https://maps.app.goo.gl/GetFPYXM5SS88h8m9`).

## 🚀 Quick Start

### 1. Installation

```bash
npm install
```

### 2. Database Sync & Seeding

```bash
npx prisma db push
```

### 3. Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ Build for Production

```bash
npm run build
npm run start
```
